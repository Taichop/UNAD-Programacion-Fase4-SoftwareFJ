# Sistema Integral de Gestión - Software FJ (Fase 4)

Repositorio colaborativo para el desarrollo del Componente Práctico (Prácticas Simuladas) del curso **Programación (213023)** de la **Universidad Nacional Abierta y a Distancia (UNAD)**.

## 🎯 Objetivo del Proyecto
Desarrollar una aplicación orientada a objetos en Python, sin motor de base de datos, para gestionar clientes, servicios (reservas de salas, alquiler de equipos y asesorías especializadas) y reservas de la empresa **Software FJ**, implementando un manejo robusto de excepciones (`try/except/else/finally`, excepciones personalizadas y encadenamiento) y registro de eventos mediante `logging`.

## 🛠️ Reglas de Flujo de Trabajo en GitHub
1. Ningún integrante debe hacer *push* directo a la rama `main`.
2. Cada integrante debe crear su propia rama a partir de `main`, realizar *commits* frecuentes y descriptivos, y abrir un **Pull Request (PR)** vinculado a su **Issue** correspondiente.
3. El código final consolidado se ejecuta en el archivo `Software_FJ_Fase4.ipynb` y genera el registro automático en `software_fj.log`.
